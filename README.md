# Coupling foundation AI with nanosensor profiling of organoid culture media for neuroprotective drug discovery

Analysis code for Sirtori, Monroy Lopez, Roxbury and Fallini.

Ryan Institute for Neuroscience and College of Engineering, University of Rhode Island.
Correspondence: riccardo-s@uri.edu

The pipeline links a Geneformer in-silico perturbation screen of a public human
TBI single-nucleus RNA-seq cohort to (GT)15-ssDNA SWCNT nanosensor readouts of
blast-injured human cortical organoids. This repository holds the scripts that
produced the figures and reported statistics, **organized by Results section**.

---

## Reproducing the paper

Everything that can be rerun from this repository on an ordinary CPU machine runs with one
command, from any working directory, without editing a path:

```bash
git clone https://github.com/riccardo-s22/Methods_nanoAI.git
cd Methods_nanoAI
mamba env create -f envs/spectral.yml      # or: conda env create -f envs/spectral.yml
conda activate nanoai-spectral             # pip users: pip install -r envs/requirements-spectral.txt
bash reproduce.sh --list                   # every step and whether it can run here; runs nothing
bash reproduce.sh                          # all four sections, then a comparison with data/
```

`bash reproduce.sh 01 04` runs a subset, `--skip-slow` leaves out the permutation-heavy steps,
`--offline` leaves out the steps that query web services. Each section also has its own runner,
`bash <section>/run_section.sh`. Inputs are read from `data/` (never written to); outputs go to
`results/<section>/` and logs to `results/<section>/logs/`, both git-ignored.

Measured with `bash reproduce.sh` from a clean tree on an 8-core workstation (WSL2, 10 GB RAM):

| Section | Wall time | Steps passed / failed / skipped | Needs |
|---|---|---|---|
| 01 SWCNT blast classification | 1 h 04 min | 33 / 0 / 4 | nothing beyond `data/` |
| 02 Geneformer in-silico screen (CPU half) | 3 min | 16 / 0 / 13 | internet (Enrichr, STRING) |
| 03 Protein corona proteomics | 2.5 min | 2 / 0 / 0 | internet (UniProt, g:Profiler, Enrichr) |
| 04 Drug response prediction | 39 min | 17 / 0 / 7 | nothing beyond `data/` |
| all, `bash reproduce.sh` | 1 h 48 min | 68 / 0 / 24 | |
| all, `bash reproduce.sh --skip-slow` | 15 min | 52 / 0 / 40 | |

**Regenerated by the rerun:** the statistics and panels of Fig. 1 and Supp. Figs. 1, 2 and 4
(shape-vector version); the proteomics figure, workbook and summary; Fig. 4b, the Fig. 4g scores,
Supp. Figs. 7 and 8 and the true-log sensitivity analysis; for the Geneformer screen, everything
downstream of the shipped per-gene tables that needs no further input (candidate filter, Enrichr
tables, Supp. Fig. 6 heatmaps, cross-model consensus and Fig. 2b, Supp. Fig. 5 metric panels).
The run ends with `repro/check_results.py`, which compares the regenerated tables with the
reference tables in `data/`.

**Not regenerated, by design** (the runners print `SKIP` with the reason; this is expected):

- the GPU / cluster half of section 02: environment, GEO download and preparation, fine-tuning,
  218 perturbation array tasks (about 865 GPU-hours). The commands, in run order, are printed by
  `bash 02_geneformer_in_silico_screen/run_section.sh --print-cluster-plan`;
- every MT computation (see *Note on the MT scripts*);
- steps whose input is not in `data/`: Supp. Fig. 3 and the Gaussian version of Supp. Fig. 4
  (sham/blast peak fits), Supp. Fig. 10b-c (western-blot densitometry workbook), the pathway-driver
  and drug-target derivation of section 02 (20%-detection table), Supp. Fig. 5a-b;
- refitting the chirality peaks from raw spectra (section 04), which needs the older NumPy / SciPy
  the peak fitting was run with ([`envs/refit.yml`](envs/refit.yml));
- western blots and GraphPad panels, which involve no code.

[`docs/EXPECTED_RESULTS.md`](docs/EXPECTED_RESULTS.md) lists every number the paper reports that
a rerun regenerates, the value obtained, and the log line or file column to read it from,
including the few that do not match the manuscript.

### Running with a coding agent

[`AGENTS.md`](AGENTS.md) is the operating manual for a coding agent (Codex and others read it
automatically; [`CLAUDE.md`](CLAUDE.md) imports it for Claude Code): setup, the one-command
rerun, a figure-to-command table, what must not be attempted locally, the known caveats, and the
rules (never edit analysis logic, never write under `data/`, report mismatches). Asking an agent
to "rerun the paper" or "regenerate Supp. Fig. 6" from the repository root is enough.

`02_geneformer_in_silico_screen/figures/mt_cls_umap_RECONSTRUCTED.py`) were

## Chirality feature definition

The published chirality analyses compute pairwise features as
`log10((H_i + 1e-6) / (H_j + 1e-6))`. Fitted peak intensities `H` are of order
1e-14 to 1e-12, so that floor dominates the ratio and turns the features into
scaled height *differences* rather than log ratios.

`sensitivity_true_log_ratios/` re-runs the affected analyses with the true ratio
`log10(H_i / H_j)` and no floor. All `H` are strictly positive in every cache, so
no floor is needed. Nothing else changes — same caches, labels, seeds and
pipelines. `04_drug_response_prediction/sensitivity_true_log_ratios/README_truelog.md`
tabulates old against new for every affected statistic. The blast-classification
result is unchanged (LOO AUC 1.00 at both time points); the drug-experiment
chirality AUC moves from 0.938 to 0.887, and the day-7 NfL correlation loses
nominal significance.

The main text reports the floored values. The sensitivity re-run is included so
the dependency is inspectable.

## Data

Source data is in [`data/`](data), in subdirectories matching the four Results
sections — see [`data/README.md`](data/README.md) for formats, plate layouts and
column schemas.

| Directory | Contents |
|---|---|
| `data/01_swcnt_blast_classification/` | NIR excitation–emission spectra (2 h and 24 h reads), chirality peak features and permutation nulls |
| `data/02_geneformer_in_silico_screen/` | FT in-silico perturbation statistics (4 arms), pathway-enrichment matrices (FT and MT), drug-signature enrichment and cross-model consensus tables |
| `data/03_protein_corona_proteomics/` | Spectronaut 17 directDIA protein-group report |
| `data/04_drug_response_prediction/` | NIR spectra of the drug experiment (3 h read), chirality peak feature tables, per-well disease-axis scores |

Not in the repository, and why:

- **DIA raw files** — 18 files, 3.4 GB, each 167–212 MB, so each exceeds GitHub's
  100 MB per-file limit. Mass-spectrometry raw data belongs in a ProteomeXchange
  repository (PRIDE) and should be deposited there for the paper. `data/` holds
  the processed Spectronaut report.
- **snRNA-seq data** — public, at NCBI GEO
  [GSE209552](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE209552)
  (Garza et al. 2023). `02_geneformer_in_silico_screen/01_dataset_preparation/fetch_geo_GSE209552.sh`
  downloads it and the other scripts in that directory process it.
- **Geneformer-V2-104M** — [ctheodoris/Geneformer](https://huggingface.co/ctheodoris/Geneformer).
- **MT in-silico perturbation tables and the MT checkpoint** — not available.
  The MT model's derived pathway and drug tables are included.
- **Western blots and densitometry** — ImageJ and GraphPad Prism; available from
  the corresponding author.

Every script resolves its inputs and outputs relative to the repository, through
[`shared/repo_paths.py`](shared/repo_paths.py) (and `gf_paths.py` in section 02): inputs default
to `data/`, outputs to `results/`, and `NANOAI_DATA` / `NANOAI_RESULTS` override both. The
analysis code is otherwise unchanged: no statistic, model, seed, permutation count, filter or
plot content was touched when the paths were made portable. The as-run version, with the
absolute paths of the machines the analyses were run on (a Windows workstation for the spectral
and proteomic analyses, the URI Unity cluster for the Geneformer work), is commit `2f6dd48`.

## Software

Spectral analyses: Python 3.13, NumPy 2.5, SciPy 1.18, scikit-learn 1.9,
pandas 3.0, matplotlib 3.11. The split-Gaussian peak fitting behind the cached
chirality features was run earlier, in Python 3.10 with NumPy 2.2.6 and SciPy
1.15.3. The scripts of section 01 fix `random_state = 0` for PCA, the linear SVM
and the saga solver; the figure panels were generated before these seeds were
added, so regenerated values can differ from the published panels in the third
decimal. Geneformer work: Python 3.10, scanpy 1.11.5,
anndata 0.11.4, Geneformer V2, PyTorch with bf16 on single NVIDIA A100 80GB
GPUs, Slurm array jobs. All statistical tests are two-sided.

Environment files, with exact versions, are in [`envs/`](envs):

| File | For | Status |
|---|---|---|
| [`envs/spectral.yml`](envs/spectral.yml), [`envs/requirements-spectral.txt`](envs/requirements-spectral.txt) | everything `bash reproduce.sh` runs: sections 01, 03, 04 and the CPU half of 02 | versions of the interpreter that reproduced the results; both files were tested: the environment was created from the yml with mamba, the requirements were installed with pip into a venv, and `bash reproduce.sh --skip-slow` passed with each |
| [`envs/geneformer.yml`](envs/geneformer.yml) | the Geneformer pipeline of section 02 (GPU stages, dataset preparation) | transcribed from the paper's key resources table and the `00_environment` scripts; not created or run. Its header says which versions were exercised |
| [`envs/refit.yml`](envs/refit.yml) | optional: refitting the chirality peaks from raw spectra (three scripts of section 04) | versions of the environment that regenerated the shipped peak-feature cache bit for bit |

Section 03 additionally imports requests, statsmodels, adjustText, openpyxl and gseapy; section 01
imports joblib and Pillow. All are in the spectral environment.

## Not included

This repository holds the scripts behind the paper. Left out, and where they
live in the source tree:

- `exp1/` — a superseded pilot of the blast-classification experiment
  (convolutional autoencoder on 16 vs 16 wells, `dim477` latent features). The
  published analysis is the 32-vs-32 interleaved design in section 1.
- `exp2_unsup*.py`, `exp2_zprime.py`, `exp3_zprime.py`, `exp3_umap.py`,
  `exp3_pairdist.py`, `exp3_sham_mg132sham.py`, `exp3_vs_exp2_chirality.py`,
  the ElasticNet variants and the 6 h and 7 d spectral time points —
  exploratory analyses not reported.
- the zero-shot in-silico perturbation pipeline on the pretrained model
  (`scripts/02`–`11`, `perturb_cells_paperQC_nGene1000*.py`,
  `zeroshot_20pct_top100_enrichr.py`) and its astrocyte, microglia and
  oligodendrocyte arms. The paper's screen uses the two **fine-tuned** models.
- `paper/reviewer_concerns/` — analyses written for a reviewer response, not
  for the paper. Two of its scripts are published as Supp. Fig. 2 and appear
  here under `01_swcnt_blast_classification/`.
